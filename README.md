# POSCO Future M 스마트 안전지킴이 V4

브라우저 카메라를 설치 없이 AI 안전 CCTV로 사용하고, Cloudflare 기반 관리자 화면에서 여러 현장을 통합 관제하는 시연용 프로젝트입니다.

## V4 핵심 기능

### 현장 안전 CCTV

- 노트북·휴대폰 브라우저에서 `지킴이 시작`
- WebRTC 연속 영상 중앙 관제
- 안전모·보안경·마스크 미착용 의심 감지
- 한국어 음성경고와 알람 ON/OFF
- 장치별 위험구역 사용·미사용 및 원격 설정
- 관리자 화면 영상 클릭 시 대화면 고화질 관제
- 별도 마이크 스트림을 사용하는 양방향 무전

### 작업중지권

- 현장 사용자 화면의 빨간색 작업중지권 버튼
- 요청자·연락처·작업중지 사유 입력
- 요청 당시 사진 자동첨부
- 관리자 긴급 알람·브라우저 알림·실시간 요청창
- 접수, 작업중지 확인, 조치 중, 해제, 종료 상태관리
- 요청 후 관제센터 무전 자동호출 선택
- 관리자 이메일 및 외부 메시지 Webhook 전송

### 현장 사진 AI 분석

- 현재 카메라 화면을 사진으로 캡처
- 제공된 산업안전 사진분석 프롬프트를 고정 절차로 사용
- 사진에서 객관적으로 보이는 내용만 분석
- 위험점수 `R = S × L`, 확실도, 즉시조치 출력
- 결과 화면·음성 읽기·관리자 이메일 발송
- 이벤트센터에서 분석결과 재열람

### TBM 안전소통

- D-안전회의 메일 본문을 TBM 요점으로 자동정리
- 사용자 화면에서 TBM 요점 음성 전파
- 작업자 의견 수집
- AI가 추가 위험요인과 보완 안전조치 생성
- 담당자 메일 발송
- 이전 의견을 다음 TBM 생성 때 참고하는 누적 학습형 구조
- Gmail 자동수신용 Apps Script 예제 포함

## 필수·선택 설정

기본 관제·무전·작업중지권의 **화면 알림**은 배포 직후 작동합니다.

다음 기능은 Cloudflare 환경변수 또는 Secret 설정이 필요합니다.

| 기능 | 설정 |
|---|---|
| 세션 보안 | `SESSION_SECRET` |
| Workers AI | `AI` binding, `WORKERS_AI_MODEL` |
| OpenAI 대체 분석 | `OPENAI_API_KEY`, `OPENAI_MODEL` |
| 이메일 | Cloudflare: `CLOUDFLARE_ACCOUNT_ID`, `CF_EMAIL_API_TOKEN` 또는 Resend: `RESEND_API_KEY`; 공통 `EMAIL_FROM`, `ADMIN_EMAIL` |
| 메시지 Webhook | `NOTIFY_WEBHOOK_URL` |
| TBM 메일 자동수신 | `TBM_INBOUND_TOKEN` |
| 사내망 무전/영상 | `TURN_ICE_SERVERS` |

자세한 설정은 [`docs/V4_SETUP.md`](docs/V4_SETUP.md)를 참고합니다.

## 시험 순서

1. 사용자 모드에서 `지킴이 시작`을 누르고 카메라 권한을 허용합니다.
2. 관리자 모드의 `실시간 관제`에서 해당 장치를 클릭합니다.
3. 사용자 화면에서 빨간색 `작업중지권` 버튼을 누르고 사유를 입력합니다.
4. 관리자 긴급 알람·요청 모달·작업중지권 페이지를 확인합니다.
5. 요청 화면의 무전 자동연결 또는 관리자 `현장 무전 연결`을 시험합니다.
6. 사용자 `현장 사진 AI 분석`을 눌러 분석결과·음성·메일 상태를 확인합니다.
7. 관리자 `TBM 안전소통`에 D-안전회의 메일 본문을 붙여 넣고 AI 요약을 생성합니다.
8. 사용자 화면에서 TBM을 듣고 작업자 의견을 제출합니다.

## 실시간 영상 품질

현재 구현은 WebRTC P2P입니다. 한 관리자가 한 현장을 크게 보는 경우에는 대화면 고화질 모드로 자동 전환하고, 여러 장치 카드는 저비트레이트 모드로 유지합니다. 사내 방화벽 또는 대칭형 NAT에서 영상·음성이 연결되지 않으면 TURN을 설정해야 합니다. 다수 관리자·다수 현장을 장시간 관제하는 운영형 환경에서는 Cloudflare Realtime SFU로 전환하는 설계를 권장합니다.

## 안전·개인정보 주의

- AI 결과는 현장 관리자의 판단을 지원하는 보조정보입니다.
- 사진에서 확인되지 않는 법령 준수 여부나 작업절차 이행 여부를 단정하지 않습니다.
- 운영 전 현장 데이터 성능검증, 개인정보·영상정보 처리기준, 보존기간, 접근권한, 오픈소스·AI 모델 라이선스 검토가 필요합니다.
- 작업중지권 요청은 불이익 판단이나 징계 자동화에 사용하지 않고 신속한 현장 확인과 안전조치를 지원하는 용도로 사용합니다.
