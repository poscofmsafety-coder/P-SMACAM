# POSCO Future M 스마트 안전지킴이 — 브라우저 무설치 관제판

이 저장소 전체를 GitHub 루트에 올리면 Cloudflare **Workers**에서 화면과 API를 함께 배포합니다. Python, VS Code, PowerShell, 별도 Edge Agent 설치가 필요하지 않습니다.

## 사용 흐름

1. 각 노트북에서 배포 사이트를 Chrome 또는 Edge로 엽니다.
2. 상단의 **지킴이 ON**을 누릅니다.
3. 최초 한 번 카메라 권한을 **허용**합니다.
4. 장치 이름·사업장·설치 구역을 저장합니다.
5. 관리자도 같은 사이트의 **통합 대시보드/실시간 관제**에서 각 노트북 프리뷰와 상태를 확인합니다.

현장 전용 주소는 `/guard`입니다.

## 현재 구현

- 브라우저 노트북 카메라 연결
- 브라우저 내 TensorFlow.js 사람 감지
- 위험구역 진입 감지 및 한국어 음성 경고
- 장치별 고유 ID 자동 발급
- 5초 간격 중앙 관제 프리뷰
- 10초 간격 Heartbeat와 온라인/오프라인 표시
- 이벤트 스냅숏 및 로그를 D1에 저장
- 여러 노트북 동시 관제
- 관리자 위험구역 원격 설정
- 안전모·지게차·넘어짐 음성/이벤트 시연 버튼

안전모·보안경·안전대·후크·지게차의 실제 자동 판별은 전용 AI 모델을 추가 연결해야 합니다. 현재 자동 분석은 사람과 위험구역 중심입니다.

## Cloudflare 설정

- 서비스: **Workers**
- Build command: 비워두기
- Deploy command: `npx wrangler deploy`
- Root directory: `/`
- 저장소: D1만 사용, R2 사용 안 함

## 중요

브라우저 보안상 사용자가 **지킴이 ON**을 직접 누르고 최초 카메라 권한을 허용해야 합니다. 탭을 닫거나 지킴이 OFF를 누르면 장치가 오프라인으로 전환됩니다. 중앙 관제 화면은 연속 동영상 스트리밍이 아니라 기본 5초 간격의 저용량 프리뷰 방식입니다.
