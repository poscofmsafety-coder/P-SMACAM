스마트 안전지킴이 V4 GitHub 업로드

1. ZIP 압축을 풉니다.
2. 폴더 안의 파일/폴더 전체를 기존 GitHub 저장소 루트에 덮어씁니다.
3. Commit changes를 누릅니다.
4. Cloudflare Workers Builds의 자동 배포가 완료될 때까지 기다립니다.
5. 관리자와 사용자 브라우저에서 Ctrl+F5로 강력 새로고침합니다.

Cloudflare 설정
- 서비스: Workers
- Build command: 없음
- Deploy command: npx wrangler deploy
- Root directory: /
